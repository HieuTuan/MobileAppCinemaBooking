# CineLuxe Spring Boot API

Run locally:

```powershell
cd backend
mvn spring-boot:run
```

Flutter Android emulator defaults:

- REST: `http://10.0.2.2:8080`
- WebSocket: `ws://10.0.2.2:8080/ws/showtimes/{showtimeId}/seats?token=...`

Flutter on a real Android phone connected to the same Wi-Fi:

```powershell
# Find your PC LAN IPv4, for example 192.168.1.15
ipconfig

# Terminal 1: run backend
cd backend
mvn spring-boot:run

# Terminal 2: run Flutter on the phone
flutter run -d <device-id> --dart-define=DEV_SERVER_HOST=192.168.1.15
```

This config makes Flutter use:

- REST: `http://192.168.1.15:8080`
- WebSocket: `ws://192.168.1.15:8080/ws/showtimes/...`

For payment links generated by the backend, set the same public/LAN base URL:

```powershell
$env:BOOKING_API_BASE_URL="http://192.168.1.15:8080"
mvn spring-boot:run
```

Make sure Windows Firewall allows inbound traffic to port `8080`, and keep the
phone and PC on the same network.

The current slice implements seat state retrieval, pessimistically locked seat
holds, automatic hold expiry, real-time seat broadcasts, food combos, and
booking creation.
